# Should you give this man a chance?

Sherita Janielle's flowchart ([the reel](https://www.instagram.com/reel/DeKs-qdvu4l/), [@sheritajanielle](https://www.instagram.com/sheritajanielle/)) as a one-question-at-a-time page.

Static site: `index.html`, `style.css`, `app.js`, one self-hosted font (Bricolage Grotesque, OFL, in `fonts/`). No backend, no tracking, no external scripts.

The question wording in `app.js` is hers, from the whiteboard. Design notes are in `DESIGN.md`.
